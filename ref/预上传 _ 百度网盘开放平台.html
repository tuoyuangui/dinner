更新时间： 2026-09-09

接口描述 权限说明 请求结构 请求参数 响应参数 错误码 请求示例 响应示例 注意事项

接口描述

Section titled “接口描述”

预上传用于通知网盘云端新建上传任务，云端返回唯一的 uploadid 标识该任务。

权限说明

Section titled “权限说明”

本接口必须经过用户授权后才可正常使用，具体授权流程和机制请参见使用入门 > 接入授权。

/rest/2.0/xpan/file?method=precreate 仅支持访问 /apps/{appname} 目录下的文件。

请求结构

Section titled “请求结构”
项目内容
HTTP MethodPOST
HTTP URLhttps://pan.baidu.com/rest/2.0/xpan/file
固定查询参数method=precreate
Content-Typeapplication/x-www-form-urlencoded

请求参数

Section titled “请求参数”
参数名称类型是否必填描述
methodstring是示例：precreate；本接口固定为 precreate。
access_tokenstring是示例：<ACCESS_TOKEN>；接口鉴权参数。
pathstring是示例：/apps/<APP_NAME>/filename.jpg；上传后使用的文件绝对路径，需要 URL 编码。
sizeint是示例：2626327；文件大小，单位 B；上传目录时固定为 0。
isdirint是示例：0；是否为目录：0 文件，1 目录。
block_liststring是示例：["<BLOCK_MD5_0>"]；各分片 MD5 组成的 JSON 字符串数组，MD5 使用 32 位小写。
autoinitint是示例：1；本接口固定为 1。
rtypeint否示例：1；冲突处理策略：1 冲突时重命名，2 冲突且 block_list 不同时重命名，3 覆盖同名文件。
uploadidstring否示例：<UPLOAD_ID>；已有上传任务的 ID。
content-md5string否示例：<CONTENT_MD5>；文件 MD5，32 位小写。
slice-md5string否示例：<SLICE_MD5>；文件前 256 KB 校验段的 MD5，32 位小写。
local_ctimestring否示例：1595919297；客户端创建时间，默认当前时间戳。
local_mtimestring否示例：1595919297；客户端修改时间，默认当前时间戳。

响应参数

Section titled “响应参数”
字段路径类型描述
errnoint业务错误码，0 表示成功。
request_iduint64请求唯一标识。
pathstring文件绝对路径。
uploadidstring上传任务唯一 ID。
return_typeint系统内部状态字段。
block_listarray需要上传的分片序号列表，索引从 0 开始。

错误码

Section titled “错误码”
业务码错误描述
-7文件或目录名错误或无权访问
-10容量不足

更多错误码请参考平台简介 > 错误码中的公共错误码。

注意事项

Section titled “注意事项”
  1. 执行请求示例代码时，将 access_token 替换为自行获取的有效令牌；文档、日志和截图中只使用 <ACCESS_TOKEN> 占位。
  2. 当云端已有 test.txt 时，重命名策略会生成 test(1).txt；目录冲突时会生成 dir(1)。
  3. 文件小于 4 MB 时，block_list 只包含文件整体 MD5；文件大于 4 MB 时，需要在本地切分并按顺序提交每个分片的 MD5。
  4. path、size 和 block_list 必须与后续分片上传和创建文件阶段保持一致。
